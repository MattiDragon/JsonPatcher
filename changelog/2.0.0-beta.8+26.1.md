- Add new `events` library for interacting with fabric events
  - In the future custom events may also get added
  - Added `hotswap_events` config option to switch between fast events and developer convenience
- Added new `mod:jsonpatcher:async` library
  - Provides mutexes and rw-locks for use in shared libraries
- Lots of internal renames to match correct terminology
  - Shows up in global directories
- Added new `ctx` global variable, containing context about the execution environment
- Default patching timeout is now 500ms, instead of 100ms
  - This should allow for more leeway in cases where the JIT is slow to optimize patches
- Setting the patching timeout to a negative number now disables it
  - This is mostly useful for development of JsonPatcher itself, but can be used by anyone
- Ported to 26.1
- Switched to new, cleaner icon
